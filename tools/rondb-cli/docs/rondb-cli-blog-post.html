Introducing RonDB CLI: One Shell to Rule Them All

We're excited to announce RonDB CLI, a new unified command-line interface that brings together all of RonDB's powerful capabilities into a single, intuitive shell. Whether you're running SQL queries, executing Redis commands, or performing high-performance primary key lookups, RonDB CLI has you covered.

The Challenge: Multiple Interfaces, Multiple Tools

RonDB is a unique database that combines the best of multiple worlds: full MySQL SQL support, Redis-compatible key-value operations, and a high-performance REST API. But until now, interacting with these different interfaces meant juggling multiple tools:

  • MySQL client for SQL queries
  • redis-cli for Rondis commands
  • curl or custom scripts for REST API calls

This fragmentation made it harder to explore, debug, and benchmark RonDB effectively.

The Solution: RonDB CLI

RonDB CLI follows a simple philosophy: "3-minute win" — connect, diagnose, and decide in under 3 minutes. It provides a single shell that automatically routes your commands to the right interface:

  • MySQL — Full SQL support for queries, schema management, and data manipulation
  • REST API — High-performance primary key lookups using a human-readable DSL
  • RonSQL — Aggregation queries (COUNT, SUM, AVG, MIN, MAX) via the REST API
  • Rondis — Redis-compatible commands for key-value operations

Smart Command Routing

RonDB CLI automatically detects what type of command you're running. Just type your command and the shell figures out where to send it:

# SQL queries are routed to MySQL
rondb> SELECT * FROM mydb.users WHERE id = 1;

# Redis commands go to Rondis
rondb> SET user:1001 "John Doe"
rondb> GET user:1001

# REST API primary key lookups
rondb> READ mydb.users id, name, email FILTER user_id=1001;

# Aggregation queries via RonSQL
rondb> RONSQL SELECT COUNT(*), SUM(amount) FROM mydb.orders;

REST API Made Easy

One of the most powerful features is the Domain-Specific Language (DSL) for REST API operations. Instead of crafting JSON by hand, you write simple, readable commands:

rondb> READ mydb.users id, name, email FILTER user_id=1001;

Request:
{
  "filters": [
    {"column": "user_id", "value": 1001}
  ],
  "readColumns": [
    {"column": "id", "dataReturnType": "default"},
    {"column": "name", "dataReturnType": "default"},
    {"column": "email", "dataReturnType": "default"}
  ]
}

Response:
{
  "data": {
    "id": 1001,
    "name": "John Doe",
    "email": "john@example.com"
  }
}
(12.3ms)

You can even batch multiple lookups in a single request:

rondb> BATCH READ mydb.users id, name FILTER user_id=1 OP 1 READ mydb.users id, name FILTER user_id=2 OP 2;

Built-in Benchmarking

RonDB CLI includes a comprehensive benchmarking suite. Load test data, run performance tests, and get detailed latency statistics — all from within the shell:

# Load 200,000 keys (4 threads x 5000 ops x 10 rows)
rondb> .load_rondis 4 5000 10

# Benchmark with 20% writes
rondb> .bench_rondis 4 10000 1 20

# Results include p95, p99, p99.9 latencies
Throughput: 45230 ops/sec
Latency: min=0.1ms avg=0.9ms max=15.2ms p95=2.1ms p99=4.5ms p99.9=12.3ms

Interactive Database Browser

Explore your databases with the built-in TUI (Terminal User Interface) browser. Navigate databases, view table schemas, and preview data — all with keyboard shortcuts:

rondb> .browse

Use j/k to navigate, Enter to select, and d to toggle between schema and data views.

Easy Configuration

Connect to your RonDB cluster with simple command-line flags or environment variables:

# Connect with flags
./rondb --host myrondb.example.com --mysql-user admin -p --tls

# Or use environment variables
export RONDB_HOST=myrondb.example.com
export RONDB_MYSQL_USER=admin
./rondb

Version Compatibility

RonDB CLI is included in the RonDB source tree starting from version 25.10, but it works with older versions too:

Interface Minimum Version
MySQL Any version
REST API 22.10
Rondis 24.10
RonSQL 24.10

Getting Started

Building RonDB CLI is straightforward:

cd tools/rondb-cli
go build -o rondb .
./rondb --host localhost

Once connected, type .help to see available commands, or .demo to run a quick interactive demonstration.
