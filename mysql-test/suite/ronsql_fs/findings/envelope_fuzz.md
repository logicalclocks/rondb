| F20 | engine (NDB API dictionary cache, in RDRS) | Intermittent, any RonSQL request soon after `CREATE TABLE` (a table with a TTL makes the RDRS TTL watcher invalidate it by name); first seen on `ronsql_fs_jit.ronsql_fs_fuzz_env`, then on the interpreter arm — timing only, not JIT.
